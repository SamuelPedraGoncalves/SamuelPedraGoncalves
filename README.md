# Olá, eu sou o Samuel Pedra 👋

Desenvolvedor full-stack. Construo sistemas web, CRMs e automações com IA para empresas brasileiras.

Na **[TechStone](https://tchstone.net)**, parceira **Bitrix24** e **Kommo**, implanto CRM e desenvolvo
integrações, automações, sistemas sob encomenda e agentes de IA.

## 🛠️ Stack

- **Front-end:** TypeScript · React · Next.js · Vite · Tailwind CSS
- **Back-end e dados:** Node.js · Express · Supabase (Postgres, Auth, Storage)
- **Deploy:** Vercel · Netlify
- **CRM e integrações:** Bitrix24 · Kommo · APIs REST · webhooks
- **IA:** agentes de IA · Gemini API · Claude
